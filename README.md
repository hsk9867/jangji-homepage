# 장지 분양상담 홈페이지 (1차 제작본)

수목장·납골당·매장묘 분양과 파묘·이장 상담 업체 홈페이지입니다. 기획서(2026-10-14) 기준으로 만들었고, 모든 화면이 전화 상담과 견적 문의로 이어지게 구성했습니다. 업체가 관리자 페이지에서 시설·후기·사진·문구를 직접 올리고 고칠 수 있습니다.

상호 "평안 장지상담", 전화 1600-0000, 사업자 정보는 **가칭·임시값**입니다. 관리자 › 기본 정보에서 실제 값으로 바꿔 주세요.

## 관리자 페이지 (`/admin.html`)
처음 열면 관리자 비밀번호(8자 이상)를 정합니다. 휴대폰에서도 쓸 수 있습니다.

| 탭 | 할 수 있는 것 |
|---|---|
| 문의 접수 | 홈페이지 상담 신청 목록, 전화 걸기, 상태(신규·연락 완료·답사 예약·계약·보류·종료), 상담 메모, 삭제, 엑셀(CSV) 받기. 30초마다 새로 고침 |
| 답사 시설 | 시설 추가·수정·삭제, 사진 여러 장 업로드·순서 변경(첫 장이 대표), 지역·가격·태그·답사 메모, 첫 화면 추천, 공개/숨김 |
| 고객 후기 | 후기 작성·수정·삭제, 사진, 진행 시설 연결(시설 페이지에 자동 표시), 첫 화면 노출, 공개/숨김 |
| 장지 안내 | 유형별 대표 사진, 소개, 평균 가격, 특징, 이장 절차, FAQ |
| 기본 정보 | 상호, 로고, 대표 전화, 상담 시간, 카톡 채널, 문의 알림 이메일, 첫 화면 사진·문구, 약속·절차, 상담 지역, 사업자 정보 |
| 설정 | 예시 자료 한꺼번에 지우기, 비밀번호 변경 |

- 시설·후기 편집창의 "저장하고 사이트에 반영"은 누르는 즉시 홈페이지에 반영됩니다. 장지 안내·기본 정보 탭은 아래 "저장하기"를 눌러야 반영되고, "미리보기"로 저장 전 모습을 새 탭에서 볼 수 있습니다.
- 사진은 브라우저에서 긴 변 1600px JPEG로 줄여서 올립니다. 아이폰 HEIC는 읽히지 않을 수 있습니다 (설정 › 카메라 › 포맷 › 높은 호환성).
- 예시 시설·후기에는 홈페이지에 "예시" 표시가 붙습니다. 실제 자료를 올린 뒤 설정 탭에서 한꺼번에 지우거나, 고쳐서 저장하면 예시 표시가 사라집니다.
- 문의 알림 메일은 카페24 PHP `mail()` 로 보냅니다. 스팸함으로 갈 수 있으니 처음 한 번 확인해 주세요.
- 비밀번호를 잊으면 FTP에서 `admin/auth.php` 를 지우고 다시 설정합니다.

## 로컬에서 확인하기
PHP 없이 확인할 수 있게 같은 API를 흉내 내는 Node 개발 서버가 있습니다.
```
node dev/server.js
```
http://localhost:8080 (관리자 /admin.html, 휴대폰 폭 미리보기 /dev/mobile.html). 로컬 관리자 비밀번호는 `dev/test-admin-password.txt` (git 제외)에 있습니다.

## 카페24에 올리기
속시원 사이트와 같은 방식입니다. 카페24 웹호스팅(PHP) 가장 낮은 요금제로 충분합니다.
1. `deploy/cafe24.local.example.ps1` 을 `deploy/cafe24.local.ps1` 로 복사해 FTP 아이디·비밀번호를 적습니다 (git 제외).
2. 배포
   ```
   powershell -ExecutionPolicy Bypass -File deploy\cafe24.ps1
   ```
   html·css·js·img·관리자 API를 올립니다. 서버에 이미 있는 `data/content.*` (관리자 저장 내용)는 덮어쓰지 않습니다.
3. FTP에서 `data`, `uploads`, `admin` 폴더 권한이 쓰기 가능(707)인지 확인합니다. 관리자 저장이 실패하면 오류 문구에 안내가 나옵니다.
4. 도메인 연결 후 무료 SSL을 신청해 https로 엽니다.
